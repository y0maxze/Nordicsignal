# NordicSignal cinematic hero

Approved visual direction: dark navy/black fintech canvas with electric blue/cyan as the primary brand, green fundamentals/OSEBX, amber insider/opportunity, red event risk and violet High Conviction/IPO research accents.

The blue angular `N`/mountain-style mark in `nordicsignal-brand.svg` is the canonical web brand mark. The home hero is a lightweight native animation rather than a blocking video: system nodes float around the NordicSignal core, connections glow, motion is disabled for `prefers-reduced-motion`, and the hero is omitted from the focused Signals view.

The approved concept artwork remains the visual reference; production UI should preserve its professional palette without pretending decorative sample numbers are live market data.
